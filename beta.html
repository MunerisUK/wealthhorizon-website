Beta testing in progress

Wealth Horizon Money Exporter is being tested. You cannot buy it today. We would rather say so than take your money for something still being worked on. It is released soon.

What beta testing means here. The program is finished enough to use, and testers are using it on their own files. What is left is the part only real files find. A bank whose CSV is laid out differently. A Money file from a version nobody has tried. A statement that does not add up for a reason we have not seen.

That work is the reason to wait. A converter you cannot check is worth nothing. Every week of testing is another set of files it has been checked against.

Hearing when it is out

Send a line to info@muneris.co.uk. We will tell you when it is on sale. Say what you are trying to convert, and we will tell you whether it is a case the program already handles.

In the meantime

  • Read what it does — the formats it reads and writes, and how it checks an import it had to guess at, are set out on the Money Exporter page.
  • You may not need it. The same engine is built into WealthHorizon as Tools → Data Transformation. If you are going to use WealthHorizon anyway, that is the one to use. What is in each edition.
  • Keep the original file. Whatever you convert with, do not throw away the .mny. It is the only copy of the original figures you have.
